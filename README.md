# XZCZNB

A Minecraft 1.12.2 Forge mod. This repository only contains the source code (`src/main/java`). 
Build scripts and resources are NOT included. This is a code backup, not a buildable project.

---

## About

A loyal zombie companion that fights for you. It can use multiple weapons, 
teleport, summon decoys, and clear everything in its path.

---

## Features

- Loyal zombie companion with multiple weapon types (bow, spear, mace, obsidian sword)
- Teleport attack and decoy summoning
- Equipment pickup and weapon switching
- Random buff/debuff on hit
- Custom powerful weapons: Mace and Spear
- Custom items: cannon, grenade, enchanted golden carrot, enchanted golden head, etc.

---

## Balance Warning

This mod adds powerful weapons (Mace and Spear) and a powerful guardian entity. 
It will break game balance. Use with caution.
